CodeBrix.WebPlatform is a set of libraries for building web applications with
a .NET backend and a Rust frontend compiled to WebAssembly: the
CodeBrix.WebPlatform.Core, CodeBrix.WebPlatform.BackendMapper and
CodeBrix.WebPlatform.FrontendBuilder assemblies, the shared Rust crate
(codebrix-webplatform) that ships inside the FrontendBuilder assembly, and the
five host-tools packages (CodeBrix.WebPlatform.FrontendBuilder.<Platform>).
The assemblies incorporate one piece of third-party source code: the shared
crate's SignalR client is derived from the signalr-client crate (MIT License);
its notice is the first entry below. Two packages also CARRY third-party
software, listed after it with where its generated notices are: the
FrontendBuilder package carries the platform's Rust crates, and each
host-tools package carries the dx and wasm-bindgen programs.

CodeBrix.WebPlatform.FrontendBuilder depends on other packages that are
distributed separately under their own licenses and are not part of it:
CodeBrix.WebPlatform.WasmShrink (which carries the wasm-opt program and the
notices for it) and CodeBrix.RustTools.

The Rust code that CodeBrix.WebPlatform.BackendMapper writes for an
application is produced from templates written for this project and from the
application's own backend; it is the application's code. Crates an
application adds of its own are the application's to record.

This file covers the libraries and their NuGet packages. The repository also
holds the source the two distributed programs are built from
(tools/dx-native-tools/sources: the dioxus-cli and wasm-bindgen-cli sources
and the crates they are built from), which is not part of any package and is
recorded in tools/dx-native-tools/notices/THIRD-PARTY-NOTICES-ToolSources.txt;
and a sample application, samples/WorkSite, which is not part of any package
and has a notices file of its own (samples/WorkSite/THIRD-PARTY-NOTICES.txt).

to you under the terms set forth in the LICENSE file, which is located at
