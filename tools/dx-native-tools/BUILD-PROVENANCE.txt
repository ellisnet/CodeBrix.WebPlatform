WHY THIS FILE EXISTS
--------------------------------------------------------------------------------
A program in a package is anonymous. This file is how anyone later can tell
which executable came from which source, which toolchain and which build
machine. Every time a program is adopted into ../../native_libraries/<rid>/,
its section here is updated from that build's output/<rid>/BUILD-INFO.txt and
the <program>.provenance.txt beside it is written from the same values.

(vendoring/dioxus-cli/PATCH-NOTES.txt, vendoring/wasm-split-cli/PATCH-NOTES.txt):
  * splitter 0007: on request (a threshold), shared code is grouped by the
    exact set of split modules that use it, and a group above the threshold
    gets a chunk of its own that only those modules fetch, so a first page no

    output is byte for byte as before;

    chunk(s) ..." line, without which the FrontendBuilder fails a split build;
  * dioxus-cli 0012: a split RELEASE build runs wasm-bindgen without --debug -
    a smaller glue file without debug checks; the .wasm is the same;
  * dioxus-cli 0013: a split module's file is named after its piece
    (module_<n>_<extern name>, module_<n>_lazy_Lazy<Component>; routes keep
    module_<n>_route<Name><hash>).
