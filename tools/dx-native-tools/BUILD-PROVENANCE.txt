WHY THIS FILE EXISTS
--------------------------------------------------------------------------------
A program in a package is anonymous. This file is how anyone later can tell
which executable came from which source, which toolchain and which build
machine. Every time a program is adopted into ../../native_libraries/<rid>/,
its section here is updated from that build's output/<rid>/BUILD-INFO.txt and
the <program>.provenance.txt beside it is written from the same values.
