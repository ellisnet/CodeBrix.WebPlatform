This file covers the WorkSite sample application under samples/WorkSite. The
notices for the CodeBrix.WebPlatform libraries and their NuGet packages are
in THIRD-PARTY-NOTICES.txt at the root of the repository.

The LICENSE file at the root of this repository (Apache License 2.0) covers
the code written for CodeBrix.WebPlatform itself, the WorkSite sample
included.

The sample is built with, and its built application contains, software
written by other people; apart from one font (below), none of it is kept in
the sample's folder. That software is NOT relicensed: every component listed
below stays under its own license.

Where a component offers a choice of licenses ("MIT OR Apache-2.0"), the
entry says which one this project uses it under.

What the CodeBrix.WebPlatform platform compiles into the application - its
shared Rust crate and the Rust crates it provides, every one of which the
WorkSite frontend builds from - is recorded by the platform, in the notices
file the CodeBrix.WebPlatform.FrontendBuilder package carries
(THIRD-PARTY-NOTICES-PlatformCrates.txt, generated in the repository at
src/CodeBrix.WebPlatform.FrontendBuilder/Rust/notices). WorkSite adds no Rust
crate of its own, so this file records only what is WorkSite's beyond the
platform. It is written by hand.

The site serves this file followed by the platform's notices, as one file at
/THIRD-PARTY-NOTICES.txt (WorkSite's build program writes it beside the
built site, in the backend project's frontend-built folder), because the
compiled application contains third-party code. It is shipped inside the
WorkSite container image.
